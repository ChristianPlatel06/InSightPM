# Project Overview

## Introduction

Modern project management requires centralized platforms that allow teams to track work, monitor progress, and collaborate effectively. Many existing solutions are either overly complex or expensive for students and small teams.

InSightPM was developed to provide a lightweight, cloud-based project management solution that offers essential project tracking functionality while maintaining simplicity and accessibility.

## Purpose

The purpose of InSightPM is to provide a secure platform where users can:

- Create projects
- Track project progress
- Organize work efficiently
- Store project information securely
- Access projects from anywhere

## Scope

The system supports:

- Authentication
- Project Management
- Cloud Data Storage
- User-Based Access Control
- Web Deployment
